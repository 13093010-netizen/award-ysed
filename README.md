# 守護阿麥伯的麥田

用 Godot 4.7 製作的像素風種田遊戲（iPad / 網頁）。

主角小麥接到電話，得知從小把自己養大的阿公阿麥伯生病住院。
為了不讓充滿一家人回憶的麥田被房東收回，小麥決定接手這塊田，讓阿公安心養病。

## 怎麼玩
打開 GitHub Pages 網址就能直接在瀏覽器玩（電腦、iPad 都可以），第一次載入要等幾秒。

## 關卡
開場故事 → 第一關 種麥田 → 第二關 冬天排水拼圖 → 第三關 蟲蟲大戰 → 第四關 收成加工 → 第五關 廚房大廚 → 終章 阿麥伯的手工湯麵 → 結局

## 檔案
- 根目錄：網頁版（Godot 匯出的 index.html、index.wasm、index.pck 等）
- `godot-project/`：Godot 原始專案，用 Godot 4.7 開啟 `project.godot`

字型：GNU Unifont（說明見 `godot-project/fonts/字型說明.txt`）
