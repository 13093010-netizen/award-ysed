# 守護阿麥伯的麥田（五關＋終章）

Godot 4.3 以上・iPad 橫向・全部用程式繪圖，不需要任何美術素材。

## 開啟
1. 安裝 Godot 4.3+（https://godotengine.org）
2. Godot → Import → 選這個資料夾的 `project.godot` → 按 F5 執行
3. 電腦上用滑鼠點 = iPad 上用手指點；手指滑過多格可以連續翻土／澆水

## 故事
主角小麥（男生）某天深夜接到媽媽的電話：從小把他養大的阿公阿麥伯生病住院了。
回家的路上看著窗外的麥田，想起小時候和阿麥伯在麥田的回憶；回到老家發現阿麥伯留給他的信——
阿麥伯早就知道自己生病，最捨不得這塊有一家人回憶的麥田，怕沒辦法種就會被房東收回。
小麥決定接手這塊田，讓阿公安心養病。（故事在 `scripts/story.gd`，台詞都在最上面的 `SCENES`、`LETTER`）

## 第一關遊戲流程
- 開場：Logo + 開始
- 春季（60 秒）：下方工具欄選工具 → 點田地
  鋤頭翻土 → 選種子播種 → 澆水、施肥。左上角四季盤會慢慢轉，春天一過就不能再動
- 夏季：發芽長大；秋季：麥穗轉黃（長得好會金黃挺直，長不好會偏黃、垂下來）
- 秋季結束：房東陳伯出場對話、看成果，給 0～3 顆信任星

## 第二關：冬天的大水
- 開場：麥田淹水、主角哭著說「幫幫我」（點一下繼續）
- 九宮格排水拼圖：左上「入口」、右下「出口」固定，其他 7 塊點兩下交換（或拖曳到另一格）
- 已經接上入口的水道會先變淡藍色當提示；接通後水流進河、田裡的水退掉
- 冬季 90 秒內完成；交換 ≤8 次 3 星、≤14 次 2 星，其他 1 星（`WINTER_LEN`、`_finish()` 可調）

## 第三關：蟲蟲大戰
- 回合制對戰：派出瓢蟲／小蘇打水／堆肥補給（回血 30，共 3 次）
- 第一戰巨大蚜蟲（怕瓢蟲），大魔王瘟神帶來白粉病（怕小蘇打水，每 3 回合放一次大招）
- 麥田血量 100，歸零會失去一條命；共 3 條命，剩幾條命就拿幾顆星
- 數值在 `ENEMIES`、`_on_action()`、`_enemy_turn()`

## 第四關：收成的季節（6 個步驟）
1. 收割：上下左右開割麥機割完 45 格麥田（有 3 顆石頭），限時 40 秒；電腦可用鍵盤方向鍵
2. 乾燥：按住「加熱」／「吹風降溫」，溫度維持 55～68°C，含水量降到 13% 完成
3. 冷藏：輸送帶送進冷藏庫，保存 3 天（自動）
4. 磨粉：按住石磨順時針畫圈，速度在綠色區，轉滿 10 圈
5. 包裝：麵粉到綠色線時按「封袋」，袋數由收割了多少決定（最多 8 袋）
6. 販售：品質越好每袋越貴（80～160 元）→ 把錢交給房東
- 收入 ≥ 800 元（`RENT`）過關；≥950 兩星、≥1100 三星；沒達標要重來

## 第五關：廚房大廚
- 爸爸點蔥油餅、媽媽點手工麵、奶奶點饅頭、弟弟點餅乾（`FAMILY`、`RECIPES` 可改）
- 點一位家人開始做，小遊戲：倒材料（按住到綠線放開）、揉麵（連點）、擀麵（左右滑）、切（看準時機）、煎煮蒸烤（火候剛好起鍋）
- 做完送餐，家人邊吃邊說「好好吃！」，四個人都送完 → 下一關

## 終章：阿麥伯的手工湯麵
- 用自己種的小麥，煮一碗阿麥伯以前常煮給小麥吃的手工湯麵
- 煮好後帶去醫院，阿麥伯謝謝小麥幫他守住麥田（煮得好不好，台詞會不一樣）
- 最後停在一家人團聚的溫馨畫面 → 結局

## 結局
五關＋終章星星加總（滿分 18），房東依總信任值說不同的話。開場畫面下方有「第1關～第5關、終章」可以直接選關測試。

## 第一關隱藏數值（在 scripts/level1.gd 的 `_evaluate()` 調整）
| 種子 | 最佳水量 | 最佳肥力 |
|---|---|---|
| 在地麥種 | 2～3 次 | 1～2.5 |
| 高產麥種 | 3～4 次 | 2～3.5（長得好時房東額外加分） |

堆肥 = 1 肥力，速效肥 = 1.5 肥力；同一格速效肥用 3 次以上會傷土。
春季長度在 `SPRING_LEN`，測試時可以按右上「快轉 ×4」或「結束春耕」。

## 像素風與字型
- 畫面用 800x600 低解析度算圖再放大（project.godot 的 stretch mode = viewport），所以整個遊戲是一格一格的像素
- 關卡程式仍用 1600x1200 座標寫，`main.gd` 會把整個遊戲縮小 0.5 倍放進 800x600
- 作物、嫩芽、工具圖示是用字元畫的像素圖，在 `scripts/art.gd` 的 `WHEAT_SPR`、`SPROUT_SPR`、`ICONS` 可以自己改
- 字型是 `fonts/unifont.otf`（GNU Unifont 像素中文字型）。字的大小請用 32、64、96，像素才會整齊
- 想換字型：改名成 `font.ttf` 或 `font.otf` 放進 `fonts/` 會優先使用

## 匯出到 iPad
1. Editor → Manage Export Templates → 下載
2. Project → Export → Add → iOS，填 Bundle Identifier（例如 com.yourname.wheat）與 Apple Team ID
3. Export Project 會產生 Xcode 專案 → 用 Xcode 開啟，接上 iPad 執行
   （要有 Apple ID；免費帳號也能裝到自己的 iPad，7 天要重新安裝一次）
